 Odin Recipes

This project is a basic recipe website built as part of The Odin Project's Foundations curriculum. 

The goal of this project is to practice foundational HTML concepts by building a multi-page website from scratch without using any CSS styling.

 Skills Demonstrated
* Setting up and managing a Git and GitHub workflow (cloning, branching, committing, pushing).
* Structuring clean, semantic HTML5 boilerplates.
* Utilizing semantic headings (`<h1>` through `<h3>`) and paragraphs.
* Constructing ordered (`<ol>`) and unordered (`<ul>`) lists for recipes and navigation.
* Managing relative directory paths and file linking between pages.
* Embedding and linking local image assets with proper alternative text.
